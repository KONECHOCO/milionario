## Review notes (App Review Information → Notes)
No login required. Trivia game with virtual prizes only (no real-money gambling).
Ads are served by Unity Ads (rewarded video is optional and user-initiated; interstitials every few games).
App Tracking Transparency: the system permission prompt appears about one second after the first launch,
before the Unity Ads SDK is initialized, so no tracking data is collected before the user decides.
To see it again: Settings > Privacy & Security > Tracking (toggle "Allow Apps to Request to Track"), or delete and reinstall the app.

## Reply to App Review (Guideline 2.1 - ATT), to paste in App Store Connect
Hello, thank you for the review. We found the cause: the App Tracking Transparency request was made
while the app was still launching (not yet in the active state), so iOS skipped the prompt. In the new
build the request is made once the app is active, about one second after launch, and the Unity Ads
SDK is initialized only after the user's choice. The attached screen recording, captured on a physical
iPhone after a fresh install, shows the launch, the ATT permission request appearing before any
tracking data is collected, and the game flow after the user's choice. Best regards.
